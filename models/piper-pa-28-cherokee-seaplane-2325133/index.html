About This Model

Priced at $119, the Piper PA-28 Cherokee Seaplane is a finished Aircraft model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.

The listing flags visualization, advertising and 3D printing as the intended applications. First published in 2025, it is part of the long-running core of the collection. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

At 56,307 polygons and 59,303 vertices this is a light asset: dense enough for close framing, and honest about what it costs a scene. It is a static build - no rig to strip out if all you need is a rendered object.
