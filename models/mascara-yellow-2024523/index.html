About This Model

Looking for a Clothing & Accessories asset? The Mascara Yellow is a finished, render-ready model at $24. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.

Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task. On this listing the stated applications are product rendering, game assets and film & TV VFX. First published in 2023, it is part of the long-running core of the collection. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Counted at the source, the model is 58,636 polygons and 33,348 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries. It is a static build - no rig to strip out if all you need is a rendered object.
