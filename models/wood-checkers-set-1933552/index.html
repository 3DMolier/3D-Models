About This Model

Wood Checkers Set is a detailed Toys & Games asset built for professional 3D pipelines, available at $15. The mesh carries 29,376 polygons and 14,738 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
