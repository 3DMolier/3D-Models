About This Model

Priced at $189, the Electric Truck with Target Trailer Rigged is a finished Vehicles model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms. On this listing the stated applications are visualization, advertising and game environments. First published in 2025, it is part of the long-running core of the collection. Common uses are automotive advertising, film and TV backgrounds, game traffic and architectural visualisation.
