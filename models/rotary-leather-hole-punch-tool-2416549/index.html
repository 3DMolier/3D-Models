About This Model

Priced at $19, the Leather Hole Punch is a finished Tools model rather than a base mesh you have to build on. Counted at the source, the model is 10,987 polygons and 11,022 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Real-world footprint is 2.2 x 21.0 x H9.16 cm, so it drops into a scene at correct scale without a rescaling pass. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is cataloged for technical visualization, film & TV VFX and product rendering. It works as a game prop, a film and TV set element, or a reference object in training material.
