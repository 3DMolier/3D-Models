About This Model

Priced at $109, the Mini Tank Drone with Gamepad is a finished Toys & Games model rather than a base mesh you have to build on. You are getting 162,129 polygons and 169,906 vertices, measured rather than estimated. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms. On this listing the stated applications are product rendering, game assets and defense simulation.

Available since 2020, the model has been through several rounds of studio use. It works for product advertising, packaging renders, game props and film set dressing.
