About This Model

Classical Antique Fireplace is a detailed Architecture Landmarks asset built for professional 3D pipelines, available at $49. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for architectural visualization, product rendering and film & TV VFX. Available since 2025, the model has been through several rounds of studio use. It is built for interior visualization, architectural renders, product advertising and game interiors.

Geometry weighs in at 22,774 polygons over 23,991 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances. It is a static build - no rig to strip out if all you need is a rendered object.
