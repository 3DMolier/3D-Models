About This Model

This Food & Beverages model - Horseshoe Shaped Salami Sausage - is ready to drop into a scene as-is, and sells for $29 on TurboSquid. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is catalogued for visualization, advertising and 3D printing. First published in 2019, it is part of the long-running core of the collection. It fits food advertising, packaging visualisation, restaurant interiors and game props.
