About This Model

OTICO Tire 20 is a detailed Vehicles asset built for professional 3D pipelines, available at $39. Counted at the source, the model is 26,047 polygons and 25,825 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 7 textures, authored at 4096 x 4096. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
