About This Model

Priced at $29, the Caulking Gun is a finished Tools model rather than a base mesh you have to build on. The mesh carries 7,191 polygons and 7,204 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 4 textures, authored at 4096 x 4096. The model uses efficient, well-organized geometry - no hidden faces or overlapping shells to clean up before rendering. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for technical visualization, film & TV VFX and product rendering. The listing dates back to 2018, and it remains one of the models we keep current. It works as a game prop, a film and TV set element, or a reference object in training material.
