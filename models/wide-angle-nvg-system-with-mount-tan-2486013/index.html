About This Model

Priced at $34, the Wide-Angle NVG System with Mount Tan is a finished Weapons model rather than a base mesh you have to build on. You are getting 43,248 polygons and 43,441 vertices, measured rather than estimated. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

Dimensions are 26.62 x 19.55 x H14.54 cm, which is what you get on import, with no unit guessing. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.
