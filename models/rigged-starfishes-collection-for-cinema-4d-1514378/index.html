About This Model

Rigged Starfishes Collection for Cinema 4D is one of the Model Bundles & Sets models in the 3D Molier catalogue, listed at $89. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. The scene is organised rather than dumped into a single mesh, which makes selective texturing and partial reuse practical.

It is catalogued for visualization, advertising and 3D printing. First published in 2020, it is part of the long-running core of the collection. The set covers several related objects at once, which saves assembling a scene from separate purchases.
