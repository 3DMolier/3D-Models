Looking for a Tools asset? The Green Face Cover Mask is a finished, render-ready model at $19. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared.

Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task.
