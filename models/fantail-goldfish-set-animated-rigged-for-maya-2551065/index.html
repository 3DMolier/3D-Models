About This Model

Fantail Goldfish Set Animated Rigged For Maya delivers orange fancy goldfish with flowing double tails that swim on loops inside Maya. The rounded egg-shaped body and long trailing fins are the hardest parts to animate, which is why the rig matters here. Fins drift behind the turn of each fish, giving the gentle wobble that real fantails show in an aquarium.

Following CheckMate rules, each fish carries clean names and pivots, so duplicates line up into a school quickly. Animation clips cover the basic swimming, saving time when the fish only need to fill a tank background. Bright scales stand out against green plants, which helps the eye follow each fish across the frame.

Out since 2026, the set suits pet store displays, aquarium apps, children's cartoons and calm relaxation videos. Shot through glass with soft caustics, a few goldfish turn an ordinary living room render into a lived-in home. Feng shui and home decor content often uses such fish as a symbol of luck and prosperity.
