About This Model

A set of fridge magnets in the souvenir style, small decorative pieces that cover a kitchen door after years of travel. The Magnet Souvenirs Collection gathers several designs in one purchase, so a fridge can look crowded without repetition. Each magnet is a thin raised shape with a flat back, which is how they sit flush against a metal surface.

Built on the StemCell standard, the set ships in several formats with PBR materials that match between them. That means the glossy paint looks the same in a game engine and in an offline renderer. It keeps every piece separate, so a single magnet can be moved or hidden on its own.

The collection has been on sale since 2025 and is licensed Royalty Free. Kitchen interiors, apartment walkthroughs and lifestyle animation use magnets to make a refrigerator feel owned. Scattered across a fridge door with a few notes, the set gives a home scene a personal history.
