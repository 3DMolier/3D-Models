About This Model

Cog Gears Mixed is a detailed Clothing & Accessories asset built for professional 3D pipelines, available at $49. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is catalogued for visualization, advertising and 3D printing. First published in 2021, it is part of the long-running core of the collection. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Geometry weighs in at 48,382 polygons over 47,397 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
