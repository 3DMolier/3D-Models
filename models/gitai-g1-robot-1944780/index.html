About This Model

GITAI G1 Robot is one of the Industrial Equipment models in the 3D Molier catalog, listed at $99. The mesh carries 809,192 polygons and 416,273 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
