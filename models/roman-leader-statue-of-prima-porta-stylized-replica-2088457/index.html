About This Model

Priced at $129, the Roman Leader Statue of Prima Porta Stylized Replica is a finished Signage & Decor model rather than a base mesh you have to build on. Counted at the source, the model is 30,693 polygons and 31,263 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else. It is cataloged for event visualization, product rendering and film & TV VFX.

Available since 2023, the model has been through several rounds of studio use. It works as set dressing for interiors and streets, advertising renders and game environments.
