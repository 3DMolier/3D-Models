About This Model

Priced at $129, the Stealth Aircraft in Flight is a finished Aircraft model rather than a base mesh you have to build on. Geometry weighs in at 198,282 polygons over 219,938 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It is a StemCell model, so it ships in TurboSquid's multi-format standard with PBR materials that carry over between renderers instead of needing to be rebuilt per engine. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets. The listing flags aerospace visualization, flight simulation and defense simulation as the intended applications.
