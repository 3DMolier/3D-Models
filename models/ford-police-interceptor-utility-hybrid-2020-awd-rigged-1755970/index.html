About This Model

Priced at $149, the Ford Police Interceptor Utility Hybrid 2020 AWD Rigged is a finished Vehicles model rather than a base mesh you have to build on. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is catalogued for visualization, advertising and game environments. Available since 2021, the model has been through several rounds of studio use. It works for game characters, crowd fills in film and TV, previsualisation and VR scenes.

Geometry weighs in at 215,999 polygons over 243,401 vertices - a mid-weight build for its class. The model is jointed, so it can be posed or animated without rebuilding the hierarchy.
