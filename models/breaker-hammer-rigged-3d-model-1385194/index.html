About This Model

Looking for a Tools asset? The Breaker Hammer Rigged is a finished, render-ready model at $49. Counted at the source, the model is 50,970 polygons and 52,689 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 11 textures, authored at 4096 x 4096. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for technical visualization, game assets and film & TV VFX. 2019 is when this one first went up, and it has stayed in the catalog since. It works as a game prop, a film and TV set element, or a reference object in training material.
