About This Model

Priced at $49, the Dahlia Franz Kafka Set is a finished Nature & Plants model rather than a base mesh you have to build on. You are getting 106,012 polygons and 129,599 vertices, measured rather than estimated. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 7 textures, authored at 4096 x 4096. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.

On this listing the stated applications are architectural visualization, film & TV VFX and product rendering. The listing dates back to 2020, and it remains one of the models we keep current. It fits environment dressing in games, architectural visualization, film backgrounds and VR scenes.
