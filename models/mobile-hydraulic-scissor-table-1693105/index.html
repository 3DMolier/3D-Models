About This Model

Looking for a Tools asset? The Mobile Hydraulic Scissor is a finished, render-ready model at $49. Counted at the source, the model is 71,211 polygons and 72,875 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else. It is cataloged for technical visualization, architectural visualization and product rendering.

Available since 2021, the model has been through several rounds of studio use. It works as a game prop, a film and TV set element, or a reference object in training material.
