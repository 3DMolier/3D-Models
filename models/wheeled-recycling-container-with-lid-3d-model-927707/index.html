About This Model

Priced at $19, the Wheeled Recycling Container with Lid is a finished Containers & Storage model rather than a base mesh you have to build on. You are getting 22,940 polygons and 23,703 vertices, measured rather than estimated. Treat the figure as a planning number: it behaves one way in a single render and another in a level with fifty instances.

The texture set counts 2 maps, delivered at 4096 x 4096. The model is watertight where it should be and open where it should be, so it behaves in both rendering and simulation. Objects sit at the origin with clean transforms, so duplicating the asset across an environment costs nothing extra.

On this listing the stated applications are technical visualization, architectural visualization and film & TV VFX. The listing dates back to 2015, and it remains one of the models we keep current. It works as warehouse and logistics set dressing, a game prop, or a product-rendering element.
