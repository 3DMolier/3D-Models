About This Model

Runway lighting is a set rather than a single fitting: threshold lights, edge lights, centreline units and the navigation lamps that mark the approach, each with its own color and mounting. Supplying them together is what lets a runway be laid out correctly rather than repeating one fixture the whole length.

The mesh is 64,322 polygons and 64,840 vertices, built entirely from quads with mixed UV layout. All-quad geometry subdivides cleanly, which is useful on fittings that sometimes need to fill a frame.

At $44 and built to CheckMate specification, it suits airport and airfield visualization, aviation infrastructure presentation, night approach scenes, simulator projects and games. On sale since 2026.
