About This Model

Worn Cargo Wagon Red is a detailed Vehicles asset built for professional 3D pipelines, available at $49. It is a StemCell model, so it ships in TurboSquid's multi-format standard with PBR materials that carry over between renderers instead of needing to be rebuilt per engine. The scene is organised rather than dumped into a single mesh, which makes selective texturing and partial reuse practical.

Buyers most often take it for visualization, advertising and game environments. 2024 is when this one first went up, and it has stayed in the catalogue since. Common uses are automotive advertising, film and TV backgrounds, game traffic and architectural visualisation.

The mesh carries 464,652 polygons and 470,832 vertices, which puts it in the mid-weight bracket for this category. It is a static build - no rig to strip out if all you need is a rendered object.
