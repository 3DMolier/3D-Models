About This Model

A set of circular saw blades with different tooth counts, covering rough ripping through to fine finishing cuts in wood. The Bosch Wood Cutting Circular Saw Blade Set totals 52,664 polygons and 52,664 vertices, spread across several discs. Seen together, the blades show at a glance how tooth density changes from one cut type to another.

Each disc follows the CheckMate standard, with clean geometry and pivots centered for rotation. Silver steel bodies with expansion slots catch highlights the way real blades do on a pegboard. The set can be fanned out on a bench or mounted one by one on a saw model.
