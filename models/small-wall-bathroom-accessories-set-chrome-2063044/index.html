About This Model

Looking for a Kitchen & Tableware asset? The Small Wall Bathroom Accessories Set Chrome is a finished, render-ready model at $15. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots.

Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
