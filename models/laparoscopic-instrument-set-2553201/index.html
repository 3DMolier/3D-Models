About This Model

Laparoscopic Instrument Set is a detailed Medical asset built for professional 3D pipelines, available at $89. The mesh carries 47,060 polygons and 47,768 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.
