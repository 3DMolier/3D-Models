About This Model

This Medical model - Cartoon Captain America Head - is ready to drop into a scene as-is, and sells for $49 on TurboSquid. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is catalogued for visualization, advertising and 3D printing. First published in 2023, it is part of the long-running core of the collection. It works for game characters, crowd fills in film and TV, previsualisation and VR scenes.

Geometry weighs in at 20,298 polygons over 10,499 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
