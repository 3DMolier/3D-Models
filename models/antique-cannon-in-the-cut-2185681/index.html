About This Model

Priced at $31, the Antique Cannon in the Cut is a finished Weapons model rather than a base mesh you have to build on. Counted at the source, the model is 53,294 polygons and 26,934 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

It is a StemCell model, so it ships in TurboSquid's multi-format standard with PBR materials that carry over between renderers instead of needing to be rebuilt per engine. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment. It is cataloged for defense simulation, game assets and film & TV VFX.

2024 is when this one first went up, and it has stayed in the catalog since. It works as a game prop, a film and TV set element, or a reference object in training material.
