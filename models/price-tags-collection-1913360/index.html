About This Model

A set of retail price tags in assorted shapes, the kind that hang from strings or clip onto shelf edges in a shop interior. Each tag is a separate object, so a store scene can scatter them across racks, garments and jars without copying one shape endlessly.

Thin card bodies carry punched holes and rounded corners, which catch a soft edge highlight when lit from above. The set passed CheckMate Pro inspection, so naming is tidy and every piece opens in place without stray geometry. Blank faces leave room for your own prices, currency marks or sale stickers applied as decals.

Three versions are offered here: the original Price Tags Collection at $29, a second set at $34 and a fourth set at $44. Each set adds different shapes, so layering them gives a market stall or boutique counter more variety. Available since 2022, these tags suit retail visualization, store planning renders and background props in shop interiors. Game designers also use them to label goods in shop menus and trading scenes.
