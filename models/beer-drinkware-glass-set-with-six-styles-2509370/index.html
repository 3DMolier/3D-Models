About This Model

Priced at $99, the Beer Drinkware Glass Set with Six Styles is a finished Food & Beverages model rather than a base mesh you have to build on. Counted at the source, the model is 11,326 polygons and 12,840 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Real-world footprint is 70.86 x 9.78 x H23.36 cm, so it drops into a scene at correct scale without a rescaling pass. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette.
