About This Model

Looking for a Toys & Games asset? The Dry Pool for Kids Size M is a finished, render-ready model at $24. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared.

The scene is organized rather than dumped into a single mesh, which makes selective texturing and partial reuse practical. Buyers most often take it for product rendering, game assets and film & TV VFX. First published in 2023, it is part of the long-running core of the collection. It works for product advertising, packaging renders, game props and film set dressing.

The mesh carries 70,462 polygons and 36,474 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. It is a static build - no rig to strip out if all you need is a rendered object.
