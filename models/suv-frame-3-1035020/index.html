About This Model

Priced at $79, the SUV Frame 3 is a finished Vehicles model rather than a base mesh you have to build on. Counted at the source, the model is 192,932 polygons and 193,048 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.
