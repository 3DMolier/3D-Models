Halogen Capeless 12V 21W Bulb Amber is a detailed Lighting asset built for professional 3D pipelines, available at $29. The mesh carries 1,790 polygons and 1,804 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.
