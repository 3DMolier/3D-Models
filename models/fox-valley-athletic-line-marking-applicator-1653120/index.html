About This Model

Looking for a Tools asset? The Line Marking Applicator is a finished, render-ready model at $49. Counted at the source, the model is 48,574 polygons and 50,591 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 10 textures, authored at 4096 x 4096. StemCell certification means the asset was authored once and delivered across formats with consistent PBR shading, which saves the conversion step when moving between renderers. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for technical visualization, film & TV VFX and game assets. It has been on sale since 2020 and is still maintained as part of the active catalog. It works as a game prop, a film and TV set element, or a reference object in training material.
