About This Model

Looking for a Furniture & Interior asset? The Bar Stool is a finished, render-ready model at $9. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene.

The scene is organised rather than dumped into a single mesh, which makes selective texturing and partial reuse practical. It is catalogued for interior design visualization, advertising and architecture presentation. 2024 is when this one first went up, and it has stayed in the catalogue since. It is built for interior visualisation, architectural renders, product advertising and game interiors.

Geometry weighs in at 966 polygons over 969 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
