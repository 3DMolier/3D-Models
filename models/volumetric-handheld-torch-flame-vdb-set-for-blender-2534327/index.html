About This Model

A set of handheld torch flames as VDB volumes for Blender, sized to crown wooden torches carried through castles, caves and catacombs. Each flame is small and lively, leaning slightly as if moved by a draft, which suits characters walking with a light source.

Because the fire is volumetric, the glow wraps around the torch head and spills onto the hand holding it. The set complies with CheckMate organization, so every flame variant is labeled and positioned for quick parenting. Variety inside the set prevents a corridor of wall sconces from looking like the same flame repeated.

Made available in 2026, it fits dungeon crawlers, medieval dramas and archaeology documentaries exploring dark tombs. Attach one to a torch held by an explorer and the surrounding darkness becomes part of the storytelling. Lower the emission strength for a dying torch when the tension in a scene needs to rise. Mob scenes with villagers carrying torches also gain realism when each flame differs slightly.
