About This Model

Can Dispenser with Cola is a detailed Containers & Storage asset built for professional 3D pipelines, available at $39. You are getting 160,434 polygons and 81,694 vertices, measured rather than estimated. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms. On this listing the stated applications are technical visualization, architectural visualization and film & TV VFX.

Available since 2023, the model has been through several rounds of studio use. It works as warehouse and logistics set dressing, a game prop, or a product-rendering element.
