About This Model

Looking for a Kitchen & Tableware asset? The Wood Created World Map is a finished, render-ready model at $29. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.

Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task. The listing flags visualization, advertising and 3D printing as the intended applications. First published in 2024, it is part of the long-running core of the collection.
