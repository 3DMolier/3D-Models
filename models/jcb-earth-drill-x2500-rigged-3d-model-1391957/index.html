About This Model

Priced at $49, the JCB Earth Drill X2500 Rigged is a finished Tools model rather than a base mesh you have to build on. Geometry weighs in at 47,264 polygons over 48,814 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

11 texture maps come with it, at 4096 x 4096 resolution. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

The listing flags technical visualization, game assets and film & TV VFX as the intended applications. First published in 2019, it is part of the long-running core of the collection. It works as a game prop, a film and TV set element, or a reference object in training material.
