About This Model

Priced at $59, the Spanish Slug is a finished Animals & Creatures model rather than a base mesh you have to build on. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for film & TV VFX, game assets and product rendering. First published in 2023, it is part of the long-running core of the collection. It suits game creatures, film and TV VFX, educational material and VR experiences.

Geometry weighs in at 910 polygons over 912 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances. It is a static build - no rig to strip out if all you need is a rendered object.
