About This Model

Looking for a Nature & Plants asset? The Nymphaea Siam Purple Leaf Set is a finished, render-ready model at $49. The mesh carries 39,535 polygons and 40,366 vertices. That is a mid-weight build: detailed enough for a foreground shot, light enough to duplicate freely. Texturing runs to 20 maps at 4096 x 4096.
