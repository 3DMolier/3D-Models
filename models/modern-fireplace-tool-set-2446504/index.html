About This Model

This Architecture & Landmarks model - Fireplace Tool Set - is ready to drop into a scene as-is, and sells for $29 on TurboSquid. You are getting 26,718 polygons and 29,945 vertices, measured rather than estimated. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.
