About This Model

Priced at $19, the Ceramic Cutter Hand Tool is a finished Tools model rather than a base mesh you have to build on. The mesh carries 11,218 polygons and 11,160 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 13.04 x 19.85 x H2.17 cm, modelled at true scale. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for technical visualization, film & TV VFX and product rendering. It works as a game prop, a film and TV set element, or a reference object in training material.
