About This Model

Priced at $29, the Eyeshadow Palette is a finished Clothing & Accessories model rather than a base mesh you have to build on. Geometry weighs in at 8,690 polygons over 8,823 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets. The listing flags product rendering, game assets and film & TV VFX as the intended applications.

First published in 2021, it is part of the long-running core of the collection. It suits fashion visualization, character dressing, product advertising and game assets.
