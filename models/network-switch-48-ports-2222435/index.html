About This Model

A rack switch is a wide flat box whose entire front is ports: two rows of network sockets with link lights between them, a management port at one end and uplink cages at the other. Counting the ports is how anyone identifies the model, so the layout has to be exactly right rather than approximate.

The mesh runs 26,358 polygons and 26,830 vertices in quads and tris with non-overlapping UVs, with the geometry in the port cages, the mounting ears and the ventilation.

At $29 and built to StemCell specification, it suits data centre and IT infrastructure visualisation, network equipment marketing, server room interiors, technical documentation and games. On sale since 2024.
