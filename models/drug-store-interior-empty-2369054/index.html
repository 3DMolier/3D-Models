About This Model

Priced at $79, the Drug Store Interior Empty is a finished Architecture & Landmarks model rather than a base mesh you have to build on. You are getting 224,887 polygons and 228,750 vertices, measured rather than estimated. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets. On this listing the stated applications are architectural visualization, film & TV VFX and product rendering.

Available since 2025, the model has been through several rounds of studio use. It is aimed at architectural visualization, city scenes, advertising renders and VR walkthroughs.

Commercial use is included. The Royalty Free license allows the model in paid client work, broadcast, published games and print; only redistributing the model file itself is excluded.

How much does the Drug Store Interior Empty 3D model cost?
