About This Model

Forest Hatchet is a detailed Tools asset built for professional 3D pipelines, available at $18. Counted at the source, the model is 1,948 polygons and 984 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment. It is cataloged for technical visualization, architectural visualization and film & TV VFX.

First published in 2023, it is part of the long-running core of the collection. It works as a game prop, a film and TV set element, or a reference object in training material.
