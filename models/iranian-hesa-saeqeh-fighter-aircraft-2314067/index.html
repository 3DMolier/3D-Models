About This Model

The Iranian HESA Saeqeh Fighter Aircraft is a production-ready Aircraft 3D model, priced at $199 on TurboSquid. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are military simulation, game environments and film production. The listing dates back to 2025, and it remains one of the models we keep current. It works for aerospace visualisation, flight and combat simulation, war-game environments and aviation sequences in film and TV.

Counted at the source, the model is 277,793 polygons and 297,133 vertices, a mid-weight load for a scene. It is a static build - no rig to strip out if all you need is a rendered object.

Can the Iranian HESA Saeqeh Fighter Aircraft model be used in a commercial project?

Commercial use is included. The Royalty Free licence allows the model in paid client work, broadcast, published games and print; only redistributing the model file itself is excluded.

Can the Iranian HESA Saeqeh Fighter Aircraft model be modified after purchase?

Editing is allowed - remesh it, strip detail for real-time use, or rebuild the shaders. The one restriction is that the model file cannot be resold or given away as an asset.

What is the Iranian HESA Saeqeh Fighter Aircraft model typically used for?

It is catalogued for military simulation, game environments and film production - the sort of work where the object needs to look right on camera but is not the subject of the shot.

What does StemCell mean for the Iranian HESA Saeqeh Fighter Aircraft model?

It means one source asset, several delivered formats, and a PBR material setup designed to read consistently across them - no rebuilding shaders after import.
