This Other model - Telescopic Arm Work Platform Lift Orange Rigged - is ready to drop into a scene as-is, and sells for $99 on TurboSquid. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.
