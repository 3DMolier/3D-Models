About This Model

Looking for a Space & Sci-Fi asset? The Grass Stylized Earth Globes Set Fur is a finished, render-ready model at $49. Counted at the source, the model is 16,384 polygons and 8,200 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.
