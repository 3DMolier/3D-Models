About This Model

Looking for a Aircraft asset? The A-29 Super Tucano Attack Aircraft is a finished, render-ready model at $149. The mesh carries 229,434 polygons and 250,904 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 11.06 x 11.19 x H3.97 m, modelled at true scale. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
