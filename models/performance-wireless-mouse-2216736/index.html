About This Model

Looking for a Electronics & Gadgets asset? The Performance Wireless Mouse is a finished, render-ready model at $29. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene.

Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment. Buyers most often take it for technical visualization, software demos and product rendering. 2024 is when this one first went up, and it has stayed in the catalog since. It is aimed at product rendering, advertising, UI and app mockups, and game and film props.

The mesh carries 29,365 polygons and 29,711 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries. It is a static build - no rig to strip out if all you need is a rendered object.
