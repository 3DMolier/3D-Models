Modern Indoor Arena Building is one of the Architecture Landmarks models in the 3D Molier catalog, listed at $249. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.

Can the Modern Indoor Arena Building model be used in a commercial project?
