About This Model

Looking for a Other asset? The Mechanical Orrery is a finished, render-ready model at $39. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene.

Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else. It is catalogued for visualization, advertising and 3D printing. 2025 is when this one first went up, and it has stayed in the catalogue since. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Geometry weighs in at 141,298 polygons over 143,118 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
