About This Model

Cross Scored Pill is a detailed Medical asset built for professional 3D pipelines, available at $9. The mesh carries 650 polygons and 640 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. The scene is organized rather than dumped into a single mesh, which makes selective texturing and partial reuse practical.
