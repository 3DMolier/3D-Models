About This Model

This Medical model - Condom Durex Box - is ready to drop into a scene as-is, and sells for $24 on TurboSquid. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is catalogued for visualization, advertising and 3D printing. First published in 2022, it is part of the long-running core of the collection. It works as warehouse and logistics set dressing, a game prop, or a product-rendering element.

Geometry weighs in at 3,294 polygons over 1,754 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
