About This Model

Priced at $19, the Plastic Lab Tank is a finished Medical model rather than a base mesh you have to build on. The mesh carries 3,566 polygons and 3,615 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 7 textures, authored at 4096 x 4096. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for medical visualization, medical simulation and defense simulation. 2019 is when this one first went up, and it has stayed in the catalog since. It fits medical education, VR anatomy training, patient-facing visualization and medical sequences in film.
