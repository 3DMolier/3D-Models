About This Model

A row of chrome open-end spanners in graded sizes, each with two angled jaws, for workshop and garage scenes. The set uses 27,072 polygons and 27,084 vertices to keep jaw edges and stamped size marks crisp.

Three maps at 4096 x 4096 render bright chrome, a satin band along each shaft and fine scratches. Built from quads alone with a clean unwrap, the spanners accept grease marks or rust without remapping. The set meets CheckMate Pro, so every jaw and handle is a sealed and tidy mesh.

Two versions are offered: the branded set at $19 and a Spanner Set Generic at $29 without maker markings. The generic edition is Royalty Free for any project, whereas the branded set is restricted to Editorial Uses Only. Hung on a pegboard or laid across a workbench, the spanners make a garage look properly equipped. Available since 2019, the tools suit car repair scenes, DIY guides, mechanic training and hardware store shelves.

By Andrey Simonenko, 3D Molier · Published June 2019 · Updated 19 November 2026
