About This Model

An inflatable arch spans a race course and marks the start or finish line of a marathon, cycling stage or obstacle run. Its 72,792 polygons and 73,600 vertices round off the air-filled tubes and the anchor points at each foot. The legs splay slightly outward, giving the arch a stable stance on asphalt or grass.

The arch is wide enough for a crowd of runners to pass beneath without breaking stride. Game Ready in the name means the build targets real-time engines, while StemCell supplies matching formats from one source. Smooth bulging surfaces carry sponsor banners or event graphics as a simple texture swap.

The Inflatable Start Finish Arch Game Ready has been offered since 2026 as one version at $39. Sports games, event planners and broadcast graphics teams use it for race days, fun runs and charity events. Place it over a road with barriers either side and the scene reads instantly as a finish straight.
