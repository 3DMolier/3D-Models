About This Model

The Fireplace Broom Fur is a production-ready Tools 3D model, priced at $19 on TurboSquid. Counted at the source, the model is 2,264 polygons and 1,138 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
