About This Model

The Harbin Z-9 Haitun is a production-ready Aircraft 3D model, priced at $129 on TurboSquid. It is a StemCell model, so it ships in TurboSquid's multi-format standard with PBR materials that carry over between renderers instead of needing to be rebuilt per engine. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

Buyers most often take it for visualization, advertising and 3D printing. 2024 is when this one first went up, and it has stayed in the catalogue since. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

The mesh carries 525,385 polygons and 280,351 vertices, which puts it in the mid-weight bracket for this category. It is a static build - no rig to strip out if all you need is a rendered object.
