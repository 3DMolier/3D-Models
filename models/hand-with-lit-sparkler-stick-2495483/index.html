About This Model

Hand with Lit Sparkler Stick is a detailed Signage & Decor asset built for professional 3D pipelines, available at $69. Counted at the source, the model is 3,460 polygons and 3,484 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Real-world footprint is 40.56 x 17.63 x H51.25 cm, so it drops into a scene at correct scale without a rescaling pass. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is cataloged for event visualization, product rendering and film & TV VFX. It works as set dressing for interiors and streets, advertising renders and game environments.
