About This Model

Six generations of iPhone in one set, from the 11 to the 16, for scenes that trace how the phone changed year by year. Laid side by side, the shift in camera layout, edge shape and screen size is visible at a glance. That makes the collection a ready timeline for comparison articles, trade-in guides and repair shop displays.

Built to CheckMate specification, every handset shares consistent scale and clean geometry, so they line up without adjustment. Each phone is a separate object, ready to be picked up by a hand model or placed in a case.

Apple holds the design rights, so this 2025 release is licensed for Editorial Uses Only. It suits tech journalism, review thumbnails, repair tutorials and museum displays about mobile history. Even lighting from above keeps reflections tidy across the glass backs, so no model in the row looks favored.
