About This Model

Priced at $39, the Basketball Uniform Set is a finished Sports & Recreation model rather than a base mesh you have to build on. The mesh carries 1,139 polygons and 1,182 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else. Buyers most often take it for product rendering, game assets and film & TV VFX.

First published in 2025, it is part of the long-running core of the collection. It fits sports broadcast graphics, game assets, advertising renders and VR experiences.
