About This Model

Looking for a Aircraft asset? The Japan Maritime P3 Orion Surveillance Plane is a finished, render-ready model at $179. Counted at the source, the model is 143,915 polygons and 153,856 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene.
