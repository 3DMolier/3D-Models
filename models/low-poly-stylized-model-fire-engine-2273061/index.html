About This Model

Low Poly Stylized Model Fire Engine belongs to our Vehicles range and is offered at $17 through the TurboSquid marketplace. Counted at the source, the model is 2,378 polygons and 2,616 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
