About This Model

This Vehicles model - Mikrotechna Praha Flight VSI UL30 Series - is ready to drop into a scene as-is, and sells for $29 on TurboSquid. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is cataloged for driving simulation, automotive advertising and film & TV VFX. First published in 2025, it is part of the long-running core of the collection. The set covers several related objects at once, which saves assembling a scene from separate purchases.

Geometry weighs in at 44,945 polygons over 45,146 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries. It is a static build - no rig to strip out if all you need is a rendered object.
