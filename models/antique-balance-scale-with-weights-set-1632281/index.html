About This Model

Balance Scale with Weights Set is an antique beam balance with brass pans and a row of stepped weights in a wooden base. Each weight sits in its own recess, so the set looks tidy when the scale is not in use. Its 19,094 polygons keep the swan-neck pillar, the pointer and the pan chains clean enough for close tabletop shots.

Texturing uses 10 maps at 4096 x 4096, giving tarnished brass and polished wood plenty of resolution. There are 18,954 vertices on a non-overlapping layout, so patina can be painted without seams across the pans. StemCell certification keeps the metal response consistent between real-time and offline rendering.

Two versions sell for $69 each, this set and a Vintage Balance Scale with Weights Set. On sale since 2020, the scale has furnished apothecary shops, law office symbolism, chemistry labs and history lessons. Placed on a desk beside old books, it gives a justice or commerce theme a quiet visual anchor.
