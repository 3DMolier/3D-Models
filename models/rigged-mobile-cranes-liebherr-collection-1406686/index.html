About This Model

A collection of Liebherr mobile cranes for construction and port scenes, with telescopic booms that dominate any skyline they enter. Mobile cranes carry their own outriggers and a cab on the carrier, so they set up quickly beside a building site. Having several machines in one set means a heavy lift can be staged with more than one crane working together.

Each crane file holds CheckMate Lite certification, so the booms and carriers open cleanly in common software. Liebherr is a real manufacturer, so the cranes are licensed Editorial Uses Only, a fit for news reports and documentary work.

Since 2019 the crane set has been a regular pick for engineering visualization, lift planning previews and construction progress animations. Extended booms read well against tall frames of steel, which makes the cranes useful in architectural renders of unfinished towers. Game levels set on docks or industrial yards also gain a lot from a crane parked beside the containers.

By Andrey Simonenko, 3D Molier · Published May 2019 · Updated 11 November 2026
