About This Model

Priced at $79, the Murena Rigged for Maya is a finished Animals & Creatures model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.

On this listing the stated applications are visualization, advertising and 3D printing. First published in 2017, it is part of the long-running core of the collection. It is ready for game assets, film and TV VFX, product rendering and VR experiences.
