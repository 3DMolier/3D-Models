About This Model

Medieval Battering Ram is one of the Weapons models in the 3D Molier catalog, listed at $59. Counted at the source, the model is 231,040 polygons and 236,872 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 18 textures, authored at 4096 x 4096. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for defense simulation, game assets and film & TV VFX. 2017 is when this one first went up, and it has stayed in the catalog since. It works as a game prop, a film and TV set element, or a reference object in training material.
