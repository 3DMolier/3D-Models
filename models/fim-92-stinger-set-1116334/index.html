About This Model

Looking for a Weapons asset? The Stinger Set is a finished, render-ready model at $89. The mesh carries 176,745 polygons and 178,801 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

15 texture maps come with it, at 4096 x 4096 resolution. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. The scene is organized rather than dumped into a single mesh, which makes selective texturing and partial reuse practical.

Buyers most often take it for defense simulation, game assets and film & TV VFX. Available since 2017, the model has been through several rounds of studio use. It works as a game prop, a film and TV set element, or a reference object in training material.
