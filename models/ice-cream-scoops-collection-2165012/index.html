About This Model

A set of round ice cream scoops with the rough, curled surface left by a scoop, ready for cones, bowls and sundae glasses. Ice Cream Scoops Collection holds 8,045 polygons and 8,017 vertices across all the balls, so the whole set stays light.

Each scoop is a separate object, so flavors can be stacked, swapped or recolored from vanilla to pistachio in seconds. UVs are non-overlapping and the set is built to CheckMate specification, which keeps names, scale and pivots tidy. No texture maps come with it, so the creamy look comes from your own shader, with subsurface scattering doing most of the work.

Released in 2023, the bundle serves dessert menus, cafe interiors, food packaging mockups and summer advertising stills. The ridged tops catch rim light well, which is what makes a scoop read as frozen rather than as a smooth sphere. Pair them with a waffle cone or a glass coupe and the set fills a dessert scene without extra modeling.
