About This Model

A set of glow sticks for marking routes, exits and casualties, the chemical lights carried by soldiers, divers and campers. The Luminous Marker Light Stick Set uses 27,930 polygons and 28,420 vertices, giving each tube a hooked cap and smooth body. Each tube has a loop at one end for hanging from a vest or tent line.

Laid side by side the set measures 34.87 x 1.6 x H21.86 cm, a handful of sticks. Non-overlapping UVs allow each stick its own glow color, so green, red and blue can sit in one row. StemCell delivery passes the emissive material into every format without any manual shader tweaking.

The set went live in 2026 and costs $29 as one complete version. Rave scenes, festival crowds, night military operations, cave diving and emergency kits use it to add colored light points. Toss a few onto a dark floor and they become both prop and practical light source.
