About This Model

Priced at $89, the Pontoon Wharf with Pedal Boats is a finished Architecture & Landmarks model rather than a base mesh you have to build on. The mesh carries 213,985 polygons and 215,284 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.
