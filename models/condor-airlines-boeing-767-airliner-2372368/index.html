About This Model

This Aircraft model - Condor Boeing 767 Airliner - is ready to drop into a scene as-is, and sells for $129 on TurboSquid. The mesh carries 447,956 polygons and 458,581 vertices. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.
