About This Model

Priced at $99, the Ring-tailed Lemur Sitting is a finished Animals & Creatures model rather than a base mesh you have to build on. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are film & TV VFX, game assets and product rendering. First published in 2024, it is part of the long-running core of the collection. It suits fashion visualization, character dressing, product advertising and game assets.

Counted at the source, the model is 11,072 polygons and 11,495 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. It is a static build - no rig to strip out if all you need is a rendered object.
