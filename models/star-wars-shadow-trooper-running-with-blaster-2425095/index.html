About This Model

Star Wars Shadow Trooper Running with Blaster is a detailed Space & Sci-Fi asset built for professional 3D pipelines, available at $129. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task.

On this listing the stated applications are game characters, film & TV VFX and product rendering. Available since 2025, the model has been through several rounds of studio use. It is built for science-fiction film and TV VFX, space simulation, game environments and VR scenes.

Counted at the source, the model is 77,275 polygons and 79,634 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries. It is a static build - no rig to strip out if all you need is a rendered object.
