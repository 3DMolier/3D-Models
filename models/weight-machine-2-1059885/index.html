About This Model

Looking for a Sports & Recreation asset? The Weight Machine 2 is a finished, render-ready model at $59. The mesh carries 99,684 polygons and 101,911 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.
