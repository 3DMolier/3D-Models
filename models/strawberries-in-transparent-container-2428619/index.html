About This Model

Looking for a Containers & Storage asset? The Strawberries in Transparent Container is a finished, render-ready model at $39. You are getting 199,350 polygons and 214,200 vertices, measured rather than estimated. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

Dimensions are 10.19 x 7.66 x H6.84 cm, which is what you get on import, with no unit guessing. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are technical visualization, architectural visualization and film & TV VFX. It works as warehouse and logistics set dressing, a game prop, or a product-rendering element.
