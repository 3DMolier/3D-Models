About This Model

Looking for a Tools asset? The Eastman Eagle S125 Static Table Cutting System is a finished, render-ready model at $59. Counted at the source, the model is 377,452 polygons and 386,936 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

8 texture maps come with it, at 8192 x 8192 and 4096 x 4096 resolution. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. The scene is organized rather than dumped into a single mesh, which makes selective texturing and partial reuse practical.

It is cataloged for technical visualization, film & TV VFX and game assets. Available since 2019, the model has been through several rounds of studio use. It works as a game prop, a film and TV set element, or a reference object in training material.
