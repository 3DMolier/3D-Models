About This Model

Priced at $49, the Small Shop Building is a finished Architecture Landmarks model rather than a base mesh you have to build on. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is catalogued for visualization, advertising and 3D printing. 2023 is when this one first went up, and it has stayed in the catalogue since. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Geometry weighs in at 256,809 polygons over 294,926 vertices - a mid-weight build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
