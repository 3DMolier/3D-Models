About This Model

Looking for a Space & Sci-Fi asset? The Sputnik 1 First Artificial Earth Satellite is a finished, render-ready model at $39. Counted at the source, the model is 7,090 polygons and 7,309 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
