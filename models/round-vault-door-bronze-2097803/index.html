About This Model

Round Vault Door Bronze is a detailed Furniture & Interior asset built for professional 3D pipelines, available at $49. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are interior visualization, product rendering and film & TV VFX. First published in 2023, it is part of the long-running core of the collection. It is built for interior visualization, architectural renders, product advertising and game interiors.

Counted at the source, the model is 57,854 polygons and 66,157 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. It is a static build - no rig to strip out if all you need is a rendered object.
