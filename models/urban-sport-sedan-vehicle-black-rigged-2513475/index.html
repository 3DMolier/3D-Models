About This Model

Priced at $149, the Urban Sport Sedan Vehicle Black Rigged is a finished Vehicles model rather than a base mesh you have to build on. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task.

On this listing the stated applications are visualization, advertising and game environments. Available since 2026, the model has been through several rounds of studio use. Common uses are automotive advertising, film and TV backgrounds, game traffic and architectural visualisation.

Counted at the source, the model is 207,472 polygons and 228,820 vertices, a mid-weight load for a scene. The model is jointed, so it can be posed or animated without rebuilding the hierarchy.
