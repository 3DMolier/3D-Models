About This Model

A crushed bottle is a different object from an intact one, and recycling imagery needs both. Compressed for transport, the shape is unpredictable, and modeling a set of them is the only honest way to fill a bale or a bin.

This is a collection listing rather than a single object, supplying the crushed bottles as static pieces. It is built to CheckMate specification.

At $57 the set suits recycling and environmental visualization, waste management presentation, education and documentary work, advertising, film set dressing and game environments. On sale since 2026.
