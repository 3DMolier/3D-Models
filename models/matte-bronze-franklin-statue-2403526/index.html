About This Model

Priced at $189, the Matte Bronze Franklin Statue is a finished Signage & Decor model rather than a base mesh you have to build on. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for event visualization, product rendering and film & TV VFX. 2025 is when this one first went up, and it has stayed in the catalog since. It works as set dressing for interiors and streets, advertising renders and game environments.

Geometry weighs in at 57,195 polygons over 57,220 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances. It is a static build - no rig to strip out if all you need is a rendered object.
