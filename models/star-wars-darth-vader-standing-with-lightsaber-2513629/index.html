About This Model

Priced at $149, the Darth Vader with Lightsaber is a finished Characters & People model rather than a base mesh you have to build on. Counted at the source, the model is 47,838 polygons and 48,638 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 90.83 x 107.95 x H182.18 cm, modelled at true scale. The model uses efficient, well-organized geometry - no hidden faces or overlapping shells to clean up before rendering. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for game characters, film & TV VFX and product rendering. It works for game characters, crowd fills in film and TV, previsualization and VR scenes.
