About This Model

Priced at $139, the Biathlon Set is a finished Weapons model rather than a base mesh you have to build on. Counted at the source, the model is 182,290 polygons and 198,313 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment. It is cataloged for defense simulation, game assets and film & TV VFX.

It has been on sale since 2021 and is still maintained as part of the active catalog. It works as a game prop, a film and TV set element, or a reference object in training material.
