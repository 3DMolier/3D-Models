About This Model

Pebble Covered Plant Pot is a detailed Kitchen & Tableware asset built for professional 3D pipelines, available at $29. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is catalogued for architecture visualization, film production and game environments. First published in 2026, it is part of the long-running core of the collection. It fits environment dressing in games, architectural visualisation, film backgrounds and VR scenes.

Geometry weighs in at 30,112 polygons over 30,703 vertices - a light build for its class. It ships 7 maps with the top set authored at 4096x4096 - enough resolution to fill a frame rather than sit in the background. It is a static build - no rig to strip out if all you need is a rendered object.
