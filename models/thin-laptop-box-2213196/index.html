About This Model

Thin Laptop Box is a detailed Kitchen & Tableware asset built for professional 3D pipelines, available at $29. You are getting 4,509 polygons and 4,621 vertices, measured rather than estimated. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.
