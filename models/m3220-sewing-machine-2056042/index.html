The Sewing Machine is a production-ready Signage & Decor 3D model, priced at $39 on TurboSquid. The mesh carries 20,431 polygons and 10,364 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.
