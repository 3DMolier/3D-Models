About This Model

A set of passport control furniture for airport arrival halls, with booths, queue barriers and counters where officers check documents. Grouping the pieces lets an artist build a full border checkpoint instead of modeling each booth and barrier separately. Queue lanes and glass booths read instantly as international travel, even in a wide establishing shot.

The bundle was prepared to the CheckMate specification, so scale and naming stay consistent across every piece in the set. Separate objects make it easy to repeat booths or extend the queue for a busier international terminal. Clean, simple surfaces suit both bright modern airports and more austere land border posts in remote regions.

This collection has been offered since 2025 as a single complete set of checkpoint furniture. Placed behind a terminal window, the set also fills background space during boarding and gate scenes. Airport planners, security training studios and travel thriller productions use it to stage arrivals and document checks.
