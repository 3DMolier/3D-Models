About This Model

Baskerville Muzzle for is a detailed Industrial Equipment asset built for professional 3D pipelines, available at $10. Counted at the source, the model is 7,090 polygons and 7,059 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.
