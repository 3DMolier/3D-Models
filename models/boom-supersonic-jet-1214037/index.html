About This Model

This Aircraft model - Boom Supersonic Jet - is ready to drop into a scene as-is, and sells for $149 on TurboSquid. Counted at the source, the model is 879,446 polygons and 898,830 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Texturing runs to 13 maps at 4096 x 4096. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.
