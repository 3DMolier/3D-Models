About This Model

MiniDV Tape is a detailed Signage & Decor asset built for professional 3D pipelines, available at $29. Counted at the source, the model is 12,147 polygons and 12,259 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 6.51 x 1.28 x H4.8 cm, modelled at true scale. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for event visualization, product rendering and film & TV VFX. It works as set dressing for interiors and streets, advertising renders and game environments.
