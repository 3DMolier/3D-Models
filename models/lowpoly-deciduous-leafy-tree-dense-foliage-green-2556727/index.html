About This Model

Priced at $39, the LowPoly Deciduous Leafy Tree Dense Foliage Green is a finished Nature & Plants model rather than a base mesh you have to build on. The mesh carries 13,096 polygons and 24,545 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 13.49 x 13.7 x H15.28 m, modelled at true scale. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for architectural visualization and film & TV VFX. It fits environment dressing in games, architectural visualization, film backgrounds and VR scenes.
