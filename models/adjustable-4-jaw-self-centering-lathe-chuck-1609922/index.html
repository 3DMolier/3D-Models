About This Model

Priced at $29, the Adjustable 4 Jaw Self Centering Lathe Chuck is a finished Tools model rather than a base mesh you have to build on. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer.
