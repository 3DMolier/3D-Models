About This Model

Hyundai HR 2023 Refrigerator is a detailed Vehicles asset built for professional 3D pipelines, available at $139. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

The listing flags visualization, advertising and 3D printing as the intended applications. First published in 2024, it is part of the long-running core of the collection. It works for interior renders, food and product advertising, and game and film set dressing.

At 816,936 polygons and 419,382 vertices this is a heavy asset: dense enough for close framing, and honest about what it costs a scene. It is a static build - no rig to strip out if all you need is a rendered object.
