About This Model

Looking for a Model Bundles & Sets asset? The Bottle Caps Collection is a finished, render-ready model at $19. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task.
