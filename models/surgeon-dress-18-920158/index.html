About This Model

Surgeon Dress 18 is a detailed Clothing & Accessories asset built for professional 3D pipelines, available at $49. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for product rendering, game assets and film & TV VFX. First published in 2015, it is part of the long-running core of the collection. It suits fashion visualization, character dressing, product advertising and game assets.

Geometry weighs in at 4,402 polygons over 4,539 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances. It ships 3 maps with the top set authored at 4096x4096 - enough resolution to fill a frame rather than sit in the background. It is a static build - no rig to strip out if all you need is a rendered object.
