About This Model

This Aircraft model - Piper Cub Aircraft - is ready to drop into a scene as-is, and sells for $99 on TurboSquid. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task.

On this listing the stated applications are aerospace visualization, film production and simulation. First published in 2024, it is part of the long-running core of the collection. It works for aerospace visualisation, flight and combat simulation, war-game environments and aviation sequences in film and TV.

Counted at the source, the model is 69,744 polygons and 71,718 vertices, a light load for a scene. It is a static build - no rig to strip out if all you need is a rendered object.
