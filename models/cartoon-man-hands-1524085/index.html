About This Model

Cartoon Man Hands is a detailed Medical asset built for professional 3D pipelines, available at $19. The mesh carries 2,330 polygons and 2,378 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Texturing runs to 5 maps at 2048 x 2048. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer.
