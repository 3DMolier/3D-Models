About This Model

A set of dressed fashion dolls with hair built as fur, ready for toy shelves, nursery scenes and collector displays. Each doll wears its own outfit, so a group shot shows variety instead of one figure repeated several times. Fur-based hair responds to light like real fibers, which flat card hair rarely manages in a close shot.

CheckMate Pro certification confirms real-world scale and tidy topology, so the dolls stand at true toy height next to furniture. Clothing and bodies are separate elements, which makes recoloring a dress or hiding an accessory a quick material change. Hair systems add render cost, so plan sampling for close portraits and lighter settings for wide room views.

Released in 2022, this collection carries an Editorial Uses Only license because the dolls belong to a famous toy brand. That suits news features, documentaries about toy history and film set dressing, not commercial work tied to the brand. A children's bedroom set with a shelf of these dolls instantly tells the viewer who lives there.
