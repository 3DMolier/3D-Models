About This Model

Priced at $69, the Military Target Drone Gray is a finished Aircraft model rather than a base mesh you have to build on. You are getting 22,584 polygons and 24,208 vertices, measured rather than estimated. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Real-world footprint is 381.5 x 670.0 x H210.39 cm, so it drops into a scene at correct scale without a rescaling pass. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Objects are grouped and named logically, so isolating a single part for a material change is a two-second job rather than a cleanup task.

On this listing the stated applications are aerospace visualization, flight simulation and defense simulation. It works for aerospace visualization, flight and combat simulation, war-game environments and aviation sequences in film and TV.
