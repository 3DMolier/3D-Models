About This Model

Priced at $99, the Royal Navy Camcopter Recon Helicopter Grey Rigged is a finished Aircraft model rather than a base mesh you have to build on. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is catalogued for aerospace visualization, film production and simulation. 2026 is when this one first went up, and it has stayed in the catalogue since. It works for aerospace visualisation, flight and combat simulation, war-game environments and aviation sequences in film and TV.

Geometry weighs in at 54,712 polygons over 58,603 vertices - a light build for its class. The model is jointed, so it can be posed or animated without rebuilding the hierarchy.
