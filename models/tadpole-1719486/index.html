About This Model

Priced at $49, the Tadpole is a finished Animals & Creatures model rather than a base mesh you have to build on. It is a StemCell model, so it ships in TurboSquid's multi-format standard with PBR materials that carry over between renderers instead of needing to be rebuilt per engine. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is cataloged for film & TV VFX, game assets and product rendering. 2021 is when this one first went up, and it has stayed in the catalog since. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Geometry weighs in at 2,580 polygons over 2,586 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries. It is a static build - no rig to strip out if all you need is a rendered object.
