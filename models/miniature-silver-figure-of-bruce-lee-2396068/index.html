About This Model

Looking for a Signage & Decor asset? The Miniature Figure of Bruce Lee is a finished, render-ready model at $79. You are getting 10,620 polygons and 10,817 vertices, measured rather than estimated. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 8.29 x 17.18 x H19.01 cm, modelled at true scale. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.

On this listing the stated applications are event visualization, product rendering and film & TV VFX. It works as set dressing for interiors and streets, advertising renders and game environments.
