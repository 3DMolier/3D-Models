About This Model

Priced at $24, the X-Rite Portable Spectrocolorimeter with Plot Display is a finished Tools model rather than a base mesh you have to build on. You are getting 26,834 polygons and 27,647 vertices, measured rather than estimated. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

Dimensions are 5.44 x 14.06 x H3.97 cm, which is what you get on import, with no unit guessing. The model uses efficient, well-organized geometry - no hidden faces or overlapping shells to clean up before rendering. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are technical visualization, film & TV VFX and product rendering. It works as a game prop, a film and TV set element, or a reference object in training material.
