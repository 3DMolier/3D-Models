About This Model

Priced at $19, the Meinl ID3GO Ibo Drum is a finished Musical Instruments model rather than a base mesh you have to build on. CheckMate is TurboSquid's manual review programme, and this model passed it: no n-gons where they would hurt, no unnamed objects, no scale surprises on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is catalogued for visualization, advertising and 3D printing. Available since 2021, the model has been through several rounds of studio use. It suits music-video and film sets, game props, product rendering and educational material.

Geometry weighs in at 5,656 polygons over 5,607 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
