About This Model

Priced at $129, the Chihuahua Rigged is a finished Other model rather than a base mesh you have to build on. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are visualization, advertising and 3D printing. It has been on sale since 2015 and is still maintained as part of the active catalogue. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Counted at the source, the model is 7,035 polygons and 6,105 vertices, a light load for a scene. Maps: 11 of them, peaking at 4096x4096, which is where the close-up detail comes from. The model is jointed, so it can be posed or animated without rebuilding the hierarchy.

By Andrey Simonenko, 3D Molier·Published December 2015·Updated 2 August 2026

Can the Chihuahua Rigged model be used in a commercial project?

Commercial use is included. The Royalty Free licence allows the model in paid client work, broadcast, published games and print; only redistributing the model file itself is excluded.

Editing is allowed - remesh it, strip detail for real-time use, or rebuild the shaders. The one restriction is that the model file cannot be resold or given away as an asset.
