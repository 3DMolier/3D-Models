About This Model

Key Machine is one of the Tools models in the 3D Molier catalog, listed at $31. Counted at the source, the model is 218,704 polygons and 112,662 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. The scene is organized rather than dumped into a single mesh, which makes selective texturing and partial reuse practical. It is cataloged for technical visualization, film & TV VFX and product rendering.

Available since 2023, the model has been through several rounds of studio use. It works as a game prop, a film and TV set element, or a reference object in training material.
