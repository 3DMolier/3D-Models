About This Model

Looking for a Characters & People asset? The Mascot Character Mobile Phone is a finished, render-ready model at $59. You are getting 5,942 polygons and 3,060 vertices, measured rather than estimated. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets. On this listing the stated applications are game characters, film & TV VFX and product rendering.
