About This Model

Priced at $29, the Sleeping Mask with Eyelashes Pattern is a finished Clothing & Accessories model rather than a base mesh you have to build on. The mesh carries 2,487 polygons and 2,594 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 12 textures, authored at 4096 x 4096 and 2048 x 2048. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for product rendering, game assets and film & TV VFX. 2019 is when this one first went up, and it has stayed in the catalog since. It suits fashion visualization, character dressing, product advertising and game assets.
