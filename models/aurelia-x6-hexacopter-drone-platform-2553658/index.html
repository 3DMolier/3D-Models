About This Model

Priced at $99, the Aurelia X6 Hexacopter Drone Platform is a finished Aircraft model rather than a base mesh you have to build on. Counted at the source, the model is 533,077 polygons and 543,326 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 106.38 x 101.51 x H59.03 cm, modelled at true scale. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for aerospace visualization and flight simulation. It works for airline and airport visualization, flight simulation, aviation sequences in film and TV, advertising renders and VR training.
