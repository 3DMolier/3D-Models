About This Model

A housekeeping cart is the object that makes a hotel corridor read as a working hotel rather than an empty set. Folded towels, stacked amenities, a linen bag hanging off one end and a bin on the other - it is a small mobile warehouse, and its clutter is exactly what sells the scene. This is a collection rather than a single cart, which matters because no two properties use the same configuration.

Having several variants in one purchase means a corridor can be dressed without the same cart appearing twice in one shot, and a housekeeping scene can be staged at different stages of a shift.

At $36 for the set and built to CheckMate specification, it is aimed at hospitality and hotel visualization, interior renders, film and television set dressing, facility management presentation and games. On sale since 2026.
