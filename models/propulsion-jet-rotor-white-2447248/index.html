About This Model

Priced at $49, the Propulsion Jet Rotor White is a finished Vehicles model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for driving simulation, automotive advertising and film & TV VFX. First published in 2025, it is part of the long-running core of the collection. It works for aerospace visualization, flight and combat simulation, war-game environments and aviation sequences in film and TV.

The mesh carries 41,787 polygons and 43,084 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances. It is a static build - no rig to strip out if all you need is a rendered object.
