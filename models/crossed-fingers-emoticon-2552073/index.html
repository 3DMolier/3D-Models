About This Model

Looking for a Other asset? The Crossed Fingers Emoticon is a finished, render-ready model at $19. Geometry weighs in at 563 polygons over 555 vertices. That sits in low-poly territory, so it stays cheap to instance across a crowd scene or a game level. It ships with 5 textures, authored at 1024 x 1024. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets. The listing flags visualization, advertising and game assets as the intended applications. It is ready for game assets, film and TV VFX, product rendering and VR experiences.
