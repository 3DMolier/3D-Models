About This Model

Ultra Large Container Cargo Ship is one of the Ships models in the 3D Molier catalogue, listed at $189. Questions About This Model

Can the Ultra Large Container Cargo Ship model be used in a commercial project?

Commercial use is included. The Royalty Free licence allows the model in paid client work, broadcast, published games and print; only redistributing the model file itself is excluded.

Can the Ultra Large Container Cargo Ship model be modified after purchase?

Yes, modification is covered by the licence. Most buyers adjust materials or decimate the mesh for their engine; only redistribution of the source file is off-limits.

What is the Ultra Large Container Cargo Ship model typically used for?

Stated applications are film production, game environments and simulation. Because the asset is finished rather than a base mesh, it also holds up as set dressing in scenes it was not specifically built for.

What does StemCell mean for the Ultra Large Container Cargo Ship model?

StemCell is TurboSquid's multi-format standard. The model was authored once and delivered in several formats with matching PBR materials, so shading survives the move between a game engine and an offline renderer.
