About This Model

Looking for a Containers & Storage asset? The Striped Drink Cup is a finished, render-ready model at $19. You are getting 13,712 polygons and 6,858 vertices, measured rather than estimated. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.
