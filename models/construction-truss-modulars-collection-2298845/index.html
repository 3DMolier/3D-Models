About This Model

Modular truss is scaffolding for things that are not buildings. Stages, screens, lighting rigs and exhibition stands are all built from the same aluminium sections, bolted into whatever shape the venue and the load require.

This is a collection listing rather than a single object, supplying the truss sections as static pieces. It is built to CheckMate specification, and further volumes of the set are offered separately.

At $38 it suits event and stage visualization, exhibition and venue presentation, construction scenes, film and television sets, game environments and editorial illustration. On sale since 2025.
