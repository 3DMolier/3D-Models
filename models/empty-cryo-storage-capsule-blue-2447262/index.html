About This Model

Looking for a Medical asset? The Empty Cryo Storage Capsule Blue is a finished, render-ready model at $39. The mesh carries 69,636 polygons and 68,487 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 13.71 x 14.13 x H21.5 cm, modelled at true scale. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for medical visualization, medical simulation and film & TV VFX. It fits medical education, VR anatomy training, patient-facing visualization and medical sequences in film.
