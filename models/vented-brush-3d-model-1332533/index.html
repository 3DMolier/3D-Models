About This Model

Priced at $19, the Vented Brush is a finished Clothing & Accessories model rather than a base mesh you have to build on. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

The listing flags visualization, advertising and 3D printing as the intended applications. First published in 2019, it is part of the long-running core of the collection. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

At 13,522 polygons and 13,958 vertices this is a light asset: dense enough for close framing, and honest about what it costs a scene. Maps: 3 of them, peaking at 2048x2048, which is where the close-up detail comes from. It is a static build - no rig to strip out if all you need is a rendered object.
