About This Model

Looking for a Tools asset? The Kitchen Torch is a finished, render-ready model at $34. Counted at the source, the model is 5,477 polygons and 5,992 vertices. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. The scene is organized rather than dumped into a single mesh, which makes selective texturing and partial reuse practical. It is cataloged for technical visualization, architectural visualization and event visualization.

First published in 2021, it is part of the long-running core of the collection. It works as a game prop, a film and TV set element, or a reference object in training material.
