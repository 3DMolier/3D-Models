About This Model

F-35 Fighter Pilot in Seated Position is a detailed Aircraft asset built for professional 3D pipelines, available at $149. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is catalogued for military simulation, game environments and film production. Available since 2025, the model has been through several rounds of studio use. It works for aerospace visualisation, flight and combat simulation, war-game environments and aviation sequences in film and TV.

Geometry weighs in at 120,533 polygons over 125,716 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
