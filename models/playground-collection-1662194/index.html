About This Model

This Model Bundles & Sets model - Playground Collection - is ready to drop into a scene as-is, and sells for $48 on TurboSquid. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for game assets, film & TV VFX and product rendering. First published in 2020, it is part of the long-running core of the collection. The set covers several related objects at once, which saves assembling a scene from separate purchases.
