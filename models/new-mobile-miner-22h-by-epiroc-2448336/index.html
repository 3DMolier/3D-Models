About This Model

Priced at $149, the New Mobile Miner 22H by Epiroc is a finished Industrial Equipment model rather than a base mesh you have to build on. The mesh carries 391,570 polygons and 431,964 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The object measures 3.86 x 22.11 x H2.02 m, modelled at true scale. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for industrial visualization, operator training and film & TV VFX. It is useful for industrial and factory visualization, product rendering, game props and technical presentations.
