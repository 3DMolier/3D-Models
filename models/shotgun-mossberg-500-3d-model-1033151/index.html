About This Model

Priced at $49, the Shotgun Mossberg 500 is a finished Weapons model rather than a base mesh you have to build on. Counted at the source, the model is 33,746 polygons and 35,128 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Texturing runs to 5 maps at 4096 x 4096. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is cataloged for defense simulation, game assets and film & TV VFX. It has been on sale since 2016 and is still maintained as part of the active catalog. It works as a game prop, a film and TV set element, or a reference object in training material.
