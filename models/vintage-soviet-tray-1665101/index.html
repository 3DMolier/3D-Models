About This Model

Vintage Soviet Tray is a detailed Kitchen & Tableware asset built for professional 3D pipelines, available at $19. You are getting 1,656 polygons and 1,658 vertices, measured rather than estimated. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.
