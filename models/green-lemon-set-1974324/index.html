About This Model

Looking for a Food & Beverages asset? The Green Lemon Set is a finished, render-ready model at $36. Geometry weighs in at 4,682 polygons over 3,107 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene.
