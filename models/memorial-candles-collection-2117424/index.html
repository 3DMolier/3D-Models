About This Model

A collection of memorial candles, the glass-cased votives placed at graves, shrines and vigils in remembrance of the dead. Each candle sits in a protective holder, which keeps the flame visible while shielding it from wind.

Certified CheckMate Pro, the collection has clean geometry and a file where each candle can be selected alone. Glass sleeves and wax surfaces are where shading matters, and a small emissive flame brings the set to life. Arranging several candles of different heights creates the layered glow typical of a cemetery at dusk.

The collection has been offered since 2023 at $34, a modest price for a complete remembrance arrangement. Film scenes of mourning, documentary reconstructions and game levels set in churchyards all use props like these. Lined along a wall or a monument base, the candles add quiet emotion without drawing focus from characters. Even a single lit candle in an otherwise dark shot carries a strong sense of memory and loss.
