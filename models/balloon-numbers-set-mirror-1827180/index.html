About This Model

A full set of foil number balloons at 47,112 polygons: nought to nine, each with the welded seam around the edge, the inflated bulge and the pinched tie point. Numbers are bought as a set because birthdays and anniversaries need arbitrary combinations, and a single digit is almost never enough.

CheckMate Pro certification means real-world scale, so any combination built from these stands at a believable height beside a figure. Non-overlapping UVs mean the mirror finish can be switched to matte or a different colour without touching geometry.

Three versions share the page: mirror, multicoloured and rainbow sets. Priced at $44 for the whole run of digits, for party and event visualisation, advertising and motion graphics.
