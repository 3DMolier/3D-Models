About This Model

Priced at $39, the Armored Wheel SUV is a finished Vehicles model rather than a base mesh you have to build on. Geometry weighs in at 19,143 polygons over 19,562 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette.
