About This Model

Curb 3m Red is a detailed Architecture & Landmarks asset built for professional 3D pipelines, available at $9. Counted at the source, the model is 1,276 polygons and 640 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.
