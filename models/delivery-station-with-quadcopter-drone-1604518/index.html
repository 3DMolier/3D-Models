About This Model

Priced at $119, the Delivery Station with Quadcopter Drone is a finished Aircraft model rather than a base mesh you have to build on. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is catalogued for aerospace visualization, film production and simulation. First published in 2020, it is part of the long-running core of the collection. It works for aerospace visualisation, flight and combat simulation, war-game environments and aviation sequences in film and TV.

Geometry weighs in at 197,427 polygons over 205,182 vertices - a light build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
