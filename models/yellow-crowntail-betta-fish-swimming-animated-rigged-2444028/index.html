About This Model

Priced at $99, the Yellow Crowntail Betta Fish Swimming Animated Rigged is a finished Animals & Creatures model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

Buyers most often take it for film production, game environments and VR experiences. First published in 2025, it is part of the long-running core of the collection. It suits game creatures, film and TV VFX, educational material and VR experiences.

The mesh carries 15,582 polygons and 15,673 vertices, which puts it in the light bracket for this category. The model is jointed, so it can be posed or animated without rebuilding the hierarchy.
