About This Model

Looking for a Vehicles asset? The Supercar BYD Yangwang U9 Red is a finished, render-ready model at $129. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer.

Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms. On this listing the stated applications are visualization, advertising and 3D printing. The listing dates back to 2025, and it remains one of the models we keep current. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Counted at the source, the model is 308,241 polygons and 343,109 vertices, a mid-weight load for a scene. It is a static build - no rig to strip out if all you need is a rendered object.
