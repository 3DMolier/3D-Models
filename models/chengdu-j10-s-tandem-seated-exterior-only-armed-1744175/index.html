About This Model

Priced at $149, the Chengdu J10 S Tandem Seated Exterior Only Armed is a finished Aircraft model rather than a base mesh you have to build on. CheckMate is TurboSquid's manual review program, and this model passed it: no n-gons where they would hurt, no unnamed objects, no scale surprises on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are aerospace visualization, flight simulation and film & TV VFX. Available since 2021, the model has been through several rounds of studio use. It works for airline and airport visualization, flight simulation, aviation sequences in film and TV, advertising renders and VR training.

Counted at the source, the model is 81,048 polygons and 83,208 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. It is a static build - no rig to strip out if all you need is a rendered object.
