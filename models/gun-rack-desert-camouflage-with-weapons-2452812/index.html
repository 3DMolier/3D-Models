About This Model

Priced at $79, the Gun Rack Desert Camouflage with Weapons is a finished Weapons model rather than a base mesh you have to build on. You are getting 362,622 polygons and 367,010 vertices, measured rather than estimated. Whether that counts as light or heavy depends on the target platform, the complexity of the scene and how many instances it carries.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.
