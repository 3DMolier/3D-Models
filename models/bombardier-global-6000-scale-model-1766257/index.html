About This Model

Bombardier Global 6000 Scale Model is a detailed Aircraft asset built for professional 3D pipelines, available at $79. Counted at the source, the model is 25,536 polygons and 25,813 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else. It is cataloged for aerospace visualization, flight simulation and film & TV VFX.

2021 is when this one first went up, and it has stayed in the catalog since. It works for airline and airport visualization, flight simulation, aviation sequences in film and TV, advertising renders and VR training.
