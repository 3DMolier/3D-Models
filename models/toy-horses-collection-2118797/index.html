About This Model

Priced at $43, the Toy Horses Collection is a finished Model Bundles & Sets model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for game assets, film & TV VFX and product rendering. First published in 2023, it is part of the long-running core of the collection. The set covers several related objects at once, which saves assembling a scene from separate purchases.
