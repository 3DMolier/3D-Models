About This Model

This Model Bundles & Sets model - Dog Muzzles Collection - is ready to drop into a scene as-is, and sells for $23 on TurboSquid. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import.
