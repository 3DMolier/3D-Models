About This Model

Priced at $29, the Amplified Antenna is a finished Electronics & Gadgets model rather than a base mesh you have to build on. Counted at the source, the model is 78,128 polygons and 79,246 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else. It is cataloged for technical visualization, software demos and film & TV VFX.

First published in 2021, it is part of the long-running core of the collection. It is aimed at product rendering, advertising, UI and app mockups, and game and film props.
