About This Model

Priced at $29, the Televes DAT BOSS MIX Amplified Antenna is a finished Electronics & Gadgets model rather than a base mesh you have to build on. Because it is CheckMate certified, the usual import checks are already done - units, pivots and material names were audited by a reviewer rather than self-declared. The scene is organized rather than dumped into a single mesh, which makes selective texturing and partial reuse practical.

Buyers most often take it for technical visualization, software demos and film & TV VFX. First published in 2021, it is part of the long-running core of the collection. It is aimed at product rendering, advertising, UI and app mockups, and game and film props.

The mesh carries 78,128 polygons and 79,246 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. It is a static build - no rig to strip out if all you need is a rendered object.
