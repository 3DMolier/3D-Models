About This Model

Priced at $39, the Water Skis is a finished Sports & Recreation model rather than a base mesh you have to build on. Counted at the source, the model is 37,358 polygons and 38,818 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 5 textures, authored at 2048 x 2048. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

It is cataloged for product rendering, game assets and film & TV VFX. 2015 is when this one first went up, and it has stayed in the catalog since. It fits sports broadcast graphics, game assets, advertising renders and VR experiences.
