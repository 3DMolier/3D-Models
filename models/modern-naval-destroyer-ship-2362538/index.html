About This Model

A modern destroyer is built around its radar. The four fixed panels on the superstructure fix the shape of the deckhouse, the vertical launch cells set the deck layout fore and aft, and the whole hull is angled to reduce radar return. This model carries that arrangement along with the gun mount, the mast array and the helicopter deck.

The mesh is 357,903 polygons and 388,741 vertices in quads and tris with non-overlapping UVs, built to StemCell specification so it works in a real-time engine as well as an offline render.

This page is unusually deep: a Type 055 variant at $199, versions paired with a Harbin helicopter at $249, and builds with a transport helicopter on the pad at $289. Aimed at naval and defence visualization, news graphics, documentary work and games.
