About This Model

Priced at $13, the Silver Jewelry Clasps Collection is a finished Model Bundles & Sets model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is cataloged for game assets, film & TV VFX and product rendering. First published in 2023, it is part of the long-running core of the collection. The set covers several related objects at once, which saves assembling a scene from separate purchases.
