About This Model

Priced at $99, the Diesel Electric Submarine Kilo Class Russian is a finished Ships & Boats model rather than a base mesh you have to build on. The mesh carries 78,043 polygons and 86,971 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Texturing runs to 23 maps at 8192 x 8192 and 4096 x 4096. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

Buyers most often take it for defense simulation, naval simulation and game environments. First published in 2017, it is part of the long-running core of the collection. Typical uses are naval and maritime scenes: film and TV VFX, harbor environments in games, and marine simulation.
