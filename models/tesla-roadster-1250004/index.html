About This Model

Priced at $129, the Tesla Roadster is a finished Vehicles model rather than a base mesh you have to build on. You are getting 133,163 polygons and 140,298 vertices, measured rather than estimated. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

It ships with 17 textures, authored at 4096 x 4096 and 2048 x 2048. Geometry is modelled to real-world proportions with a tidy edge flow, which keeps it usable both as a background element and in closer shots. Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets.

On this listing the stated applications are driving simulation, automotive advertising and game traffic. 2018 is when this one first went up, and it has stayed in the catalog since. Common uses are automotive advertising, film and TV backgrounds, game traffic and architectural visualization.
