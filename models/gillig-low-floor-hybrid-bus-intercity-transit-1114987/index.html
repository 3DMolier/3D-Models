About This Model

Looking for a Vehicles asset? The Gillig Hybrid Bus is a finished, render-ready model at $129. Counted at the source, the model is 296,284 polygons and 312,317 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances.

Texturing runs to 18 maps at 8192 x 8192 and 4096 x 4096. The mesh is built with clean quad-based topology and correct real-world proportions, so it subdivides predictably and sits at the right size next to other objects in a scene. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

It is cataloged for driving simulation, automotive advertising and game traffic. 2017 is when this one first went up, and it has stayed in the catalog since. Common uses are automotive advertising, film and TV backgrounds, game traffic and architectural visualization.
