About This Model

This Aircraft model - ZALA LANCET Kamikaze Attack Drone - is ready to drop into a scene as-is, and sells for $89 on TurboSquid. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment.

Buyers most often take it for aerospace visualization, film production and simulation. First published in 2023, it is part of the long-running core of the collection. It works for aerospace visualisation, flight and combat simulation, war-game environments and aviation sequences in film and TV.

The mesh carries 73,116 polygons and 37,467 vertices, which puts it in the light bracket for this category. It is a static build - no rig to strip out if all you need is a rendered object.
