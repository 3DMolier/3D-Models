About This Model

Looking for a Model Bundles & Sets asset? The Rigged Boxers Collection for Maya is a finished, render-ready model at $189. Topology is kept deliberately simple where detail would not read on camera, which keeps the scene light without visibly cheapening the silhouette.

Transforms are frozen and the hierarchy is shallow, which keeps the asset easy to instance across a large environment. It is cataloged for game assets, film & TV VFX and product rendering. Available since 2020, the model has been through several rounds of studio use. The set covers several related objects at once, which saves assembling a scene from separate purchases.
