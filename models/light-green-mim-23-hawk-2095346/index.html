About This Model

Light Green MIM-23 HAWK is a detailed Weapons asset built for professional 3D pipelines, available at $119. It is a StemCell model, so it ships in TurboSquid's multi-format standard with PBR materials that carry over between renderers instead of needing to be rebuilt per engine. The scene is organised rather than dumped into a single mesh, which makes selective texturing and partial reuse practical.

It is catalogued for film production, game environments and VR experiences. 2023 is when this one first went up, and it has stayed in the catalogue since. It suits game creatures, film and TV VFX, educational material and VR experiences.

Geometry weighs in at 348,067 polygons over 356,083 vertices - a mid-weight build for its class. It is a static build - no rig to strip out if all you need is a rendered object.
