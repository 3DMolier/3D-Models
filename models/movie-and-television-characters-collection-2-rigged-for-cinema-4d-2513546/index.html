About This Model

This bundle gathers a second group of screen-style characters into one purchase, so a crowd of types can fill a set without separate shopping. Each figure arrives as its own object, so one character can go into a close shot while the rest stay hidden. Bundles like this save time when a scene needs several people of different builds and outfits standing in the same frame.

The collection passed CheckMate inspection, so file structure, naming and object scale were reviewed before it went on sale. Separate hierarchies per character keep selection simple when one figure must be swapped for another between takes. Lighting artists can treat each one as an independent asset and assign materials per character.

Two versions are available at $189 each: the Movie and Television Characters Collection 2 Rigged, and a companion edition prepared for Maya. The set appeared in 2026 and is chosen for animated shorts, previsualization of crowd scenes and stylized game prototypes.
