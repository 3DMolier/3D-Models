About This Model

US Lincoln Penny 2013 is a detailed asset built for professional 3D pipelines, available at $19. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are visualization, advertising and 3D printing. First published in 2025, it is part of the long-running core of the collection. It works as set dressing for interiors and streets, advertising renders and game environments.

Counted at the source, the model is 2,816 polygons and 2,818 vertices, a light load for a scene. It is a static build - no rig to strip out if all you need is a rendered object.
