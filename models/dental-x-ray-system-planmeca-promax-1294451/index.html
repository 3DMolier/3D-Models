About This Model

Looking for a Medical asset? The Dental X-Ray System Planmeca ProMax is a finished, render-ready model at $59. It is a StemCell model, so it ships in TurboSquid's multi-format standard with PBR materials that carry over between renderers instead of needing to be rebuilt per engine.

Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms. On this listing the stated applications are medical visualization, medical simulation and software demos. 2018 is when this one first went up, and it has stayed in the catalog since. It fits medical education, VR anatomy training, patient-facing visualization and medical sequences in film.

Counted at the source, the model is 10,142 polygons and 10,890 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. Maps: 5 of them, peaking at 4096x4096, which is where the close-up detail comes from. It is a static build - no rig to strip out if all you need is a rendered object.
