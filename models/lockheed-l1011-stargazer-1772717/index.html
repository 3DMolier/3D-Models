About This Model

This Aircraft model - Lockheed L1011 Stargazer - is ready to drop into a scene as-is, and sells for $149 on TurboSquid. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

The listing flags visualization, advertising and 3D printing as the intended applications. The listing dates back to 2021, and it remains one of the models we keep current. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

At 324,919 polygons and 360,433 vertices this is a mid-weight asset: dense enough for close framing, and honest about what it costs a scene. It is a static build - no rig to strip out if all you need is a rendered object.
