About This Model

Priced at $24, the Surveyor Auto Level is a finished Tools model rather than a base mesh you have to build on. The model is CheckMate certified - a human reviewer checked the wireframe, the material assignments and the real-world dimensions before it went on sale. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are technical visualization, film & TV VFX and product rendering. The listing dates back to 2018, and it remains one of the models we keep current. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Counted at the source, the model is 19,706 polygons and 19,377 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. Maps: 8 of them, peaking at 4096x4096, which is where the close-up detail comes from. It is a static build - no rig to strip out if all you need is a rendered object.

Questions About This Model

Can the Surveyor Auto Level model be used in a commercial project?

Commercial use is included. The Royalty Free license allows the model in paid client work, broadcast, published games and print; only redistributing the model file itself is excluded.

Can the Surveyor Auto Level model be modified after purchase?

Editing is allowed - remesh it, strip detail for real-time use, or rebuild the shaders. The one restriction is that the model file cannot be resold or given away as an asset.

What is the Surveyor Auto Level model typically used for?

It is cataloged for visualization, advertising and 3D printing - the sort of work where the object needs to look right on camera but is not the subject of the shot.

Is the Surveyor Auto Level model quality-checked?

It is CheckMate certified, which on TurboSquid means a human reviewer signed off the wireframe, the naming and the scale rather than the seller self-declaring quality.
