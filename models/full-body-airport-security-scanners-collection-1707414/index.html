About This Model

Security screening is the part of an airport everyone recognizes and almost nobody models properly. A checkpoint needs more than one machine type - the walk-through arch, the millimetre wave booth with its curved panels, the operator screen - and they have to sit in a sensible order for the flow to make sense. This is a collection rather than a single scanner, which is what a believable checkpoint actually requires.

Having several units in one purchase means a terminal can be dressed with a full lane rather than the same machine repeated, and a queue can be staged around equipment that behaves like real hardware.

A second collection sits on this page at $99 for a wider selection. This set at $69 is built to CheckMate specification and aimed at airport and terminal visualization, security industry presentation, film and television, training material and games. On sale since 2021.
