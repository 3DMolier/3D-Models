About This Model

Cross Belt Sorter is a detailed Industrial Equipment asset built for professional 3D pipelines, available at $59. The StemCell build means you are not re-authoring shaders after import - the PBR setup is designed to read the same across engines. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

The listing flags industrial visualization, operator training and product rendering as the intended applications. First published in 2025, it is part of the long-running core of the collection. It is useful for industrial and factory visualization, product rendering, game props and technical presentations.

At 2,649,767 polygons and 2,663,805 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. It is a static build - no rig to strip out if all you need is a rendered object.
