About This Model

Cigarette Display is a detailed Furniture & Interior asset built for professional 3D pipelines, available at $18. The mesh carries 76,292 polygons and 75,586 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene.

The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else. Buyers most often take it for interior visualization, product rendering and film & TV VFX.

First published in 2024, it is part of the long-running core of the collection. It is built for interior visualization, architectural renders, product advertising and game interiors.
