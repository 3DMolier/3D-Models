About This Model

Looking for a Clothing & Accessories asset? The Unisex Red Cloak With Hood is a finished, render-ready model at $49. As a StemCell asset it comes with standardised PBR materials, so the look holds up whether it lands in a game engine or an offline renderer.

Naming and hierarchy are consistent, so the model behaves predictably when it is merged into a larger scene alongside other assets. On this listing the stated applications are product rendering, game assets and film & TV VFX. The listing dates back to 2019, and it remains one of the models we keep current. It suits fashion visualization, character dressing, product advertising and game assets.

Counted at the source, the model is 26,757 polygons and 26,754 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances. It ships 11 maps with the top set authored at 4096x4096 - enough resolution to fill a frame rather than sit in the background. It is a static build - no rig to strip out if all you need is a rendered object.
