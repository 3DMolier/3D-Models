About This Model

Priced at $129, the Dodge Charger 2015 Police Car is a finished Vehicles model rather than a base mesh you have to build on. CheckMate is TurboSquid's manual review program, and this model passed it: no n-gons where they would hurt, no unnamed objects, no scale surprises on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are driving simulation, automotive advertising and game traffic. Available since 2015, the model has been through several rounds of studio use. Common uses are automotive advertising, film and TV backgrounds, game traffic and architectural visualization.

Counted at the source, the model is 306,312 polygons and 322,126 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. Maps: 8 of them, peaking at 8192x8192, which is where the close-up detail comes from. It is a static build - no rig to strip out if all you need is a rendered object.
