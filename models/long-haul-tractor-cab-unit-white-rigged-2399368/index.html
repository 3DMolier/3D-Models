About This Model

Priced at $149, the Long Haul Tractor Cab Unit White Rigged is a finished Vehicles model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Pivot points sit where you would expect them, which matters as soon as the model needs to be instanced or parented to something else.

Buyers most often take it for driving simulation, automotive advertising and game traffic. First published in 2025, it is part of the long-running core of the collection. Common uses are automotive advertising, film and TV backgrounds, game traffic and architectural visualization.

The mesh carries 354,188 polygons and 365,667 vertices. Its suitability for real-time use depends on the target platform, scene complexity and the number of instances. The model is jointed, so it can be posed or animated without rebuilding the hierarchy.
