About This Model

Priced at $149, the Shaanxi KJ-500 is a finished Aircraft model rather than a base mesh you have to build on. The mesh is modelled at true scale with quad-dominant flow, so subdivision behaves and the object does not need rescaling on import. Everything is placed at the scene origin with sensible pivots, so the asset can be duplicated, arrayed or attached to a rig without hunting for transforms.

On this listing the stated applications are aerospace visualization, flight simulation and film & TV VFX. First published in 2024, it is part of the long-running core of the collection. It is ready for game assets, film and TV VFX, product rendering and VR experiences.

Counted at the source, the model is 224,848 polygons and 119,113 vertices. That figure reads differently on desktop, on mobile and in WebXR, so weigh it against the target platform and the number of instances in the scene. It is a static build - no rig to strip out if all you need is a rendered object.
