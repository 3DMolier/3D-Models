# Пакетная генерация описаний карточек - СПИТ, ДЕНЕГ НЕ ТРАТИТ

> **Состояние на 07.10.2026: линия готова, но выключена.** Основатель решил не
> платить за API сверх подписки, поэтому описания пишутся ночными сменами
> (задача `night-card-descriptions`, каждые полчаса с 00:00 до 09:00).
>
> Чтобы потратить деньги, нужны ДВА сознательных действия: переменная окружения
> с ключом и флаг `--confirm-cost`. Без флага `submit.mjs` печатает оценку и
> выходит, даже когда ключ есть. Ни одна автоматическая задача эту линию не
> вызывает.
>
> Ниже - описание на случай, если решение изменится.

Задача: 1 000-5 000 уникальных описаний за ночь вместо сотни. Ночные смены, где
текст пишу я подряд, упираются не в данные и не в правила, а в последовательность:
каждая карточка занимает место в рассуждении. Пакетный режим снимает это целиком -
партия уходит одной посылкой, считается на стороне API параллельно, а мне остаётся
приёмка, которой всё равно, сто карточек или пять тысяч.

## Как это устроено

| Файл | Что делает |
|---|---|
| `prompt.mjs` | ТЗ 2.1 как системный промпт + три эталона из уже опубликованных рукописных карточек той же категории |
| `submit.mjs` | собирает партию из справок и отправляет в Message Batches API (скидка 50%) |
| `collect.mjs` | ждёт, забирает JSONL, проверяет каждую карточку, делит на принятые и брак |
| `check.mjs` | приёмка по ТЗ: структура, длины, числа только из справки, мета-обороты, повторы между карточками |
| `run-night.mjs` | весь прогон одной командой + сводка в Telegram |

Зависимостей нет: HTTP делает встроенный `fetch`, SDK не нужен.

## Что нужно один раз

```
setx ANTHROPIC_API_KEY "sk-ant-..."
```

Ключ читается только из переменной окружения, уходит только на `api.anthropic.com`,
в логи не печатается.

## Прогон

```
node tools/batch-writer/run-night.mjs --count 2000 --model sonnet
```

Проверить плумбинг без траты денег:

```
node scripts/night-brief.mjs --slugs tools/night-writer/priority-slugs.json --count 5
node tools/batch-writer/submit.mjs --count 5 --dry
```

## Приёмка и почему она жёсткая

Три попытки отдать эту работу внешней модели в сентябре-октябре 2026 провалились на
одном и том же: выдуманные числа (миллиметры, вольты, вес), пересказ записи вместо
предмета, одни и те же пятисловные обороты на сотнях карточек. Поэтому карточка
публикуется только если прошла `check.mjs`, а затем ещё и валидатор чисел в
`scripts/night-apply.mjs`. Брак уходит в `rejects.json` и переписывается следующим
прогоном - это нормальная часть работы, а не авария.

Приёмка откалибрована по моим собственным карточкам: все 18 эталонов из текущей
очереди проходят её без правок. Если новая проверка валит эталон - неверна проверка,
а не эталон.

Если приёмку прошло меньше 60% партии, прогон останавливается сам и пишет в Telegram:
значит сломался промпт или данные, и гнать дальше - жечь деньги.

## Стоимость

Цены пакетного режима (скидка 50% уже учтена), на карточку приходится около
1 700 токенов входа и 480 выхода:

| Модель | 1 000 карточек | 5 000 | весь остаток каталога (~33 500) |
|---|---|---|---|
| Haiku 4.5 | ~$2 | ~$10 | ~$70 |
| Sonnet 5.5 | ~$4 | ~$20 | ~$135 |
| Opus 5.5 | ~$8 | ~$40 | ~$270 |

Начинать стоит с Sonnet: Haiku дешевле, но правила тут жёсткие (окна по словам и
предложениям), и доля брака съест разницу. Фактическую стоимость и долю принятых
`collect.mjs` печатает после каждой партии - через две-три ночи будет видно, стоит
ли спускаться на Haiku.

## Каждую ночь

Задача Windows ставится одной командой (от имени основателя, не от SYSTEM - иначе
переменная с ключом будет не видна):

```
schtasks /Create /TN "3DMolier Night Descriptions" /SC DAILY /ST 01:00 /RL HIGHEST /F /TR "cmd /c cd /d C:\3dmolier\Clode_and_Gpt_Website && node tools\batch-writer\run-night.mjs --count 2000 --model sonnet >> tools\batch-writer\night-log.txt 2>&1"
```

01:00 выбрано сознательно: партия считается часами, к публикации в 11:30 всё готово,
и ночной трафик API дешевле по времени ожидания. Объём меняется параметром `--count`.

## Чего эта линия НЕ делает

Не публикует. Сайт выкладывает задача Windows в 11:30, она сама увидит дописанные
карточки. Не трогает рукописные тексты: `night-apply.mjs` пишет в
`data/model-hand-desc.json`, а он главнее заготовки генератора.
